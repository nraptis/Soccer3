BitReverseCipher and retired-source cleanup — 2026-11-03

The active two-round vault now has one BitReverseCipher after all of layer 3,
including its trailing PasswordXOR. No final reversal is added. The second
round retains the same numeric bit-row grid. Individual FlameToad passes,
rotation packs, material budgets, and application counts are unchanged.
This changes ciphertext compatibility with the previous rotate-by-3 boundary.

BitReverseCipher reverses bit order inside every byte, preserving byte
positions. Seal and Unseal call the identical operation. No worker, material,
allocation, or mutable state is needed. Unaligned buffers and arbitrary
lengths are supported. Nonempty overlapping buffers are rejected.

Backends: ARM64 NEON RBIT; ARMv7 NEON masked swaps; AVX2 32-byte and SSSE3
16-byte register nibble lookups; SSE2 masked swaps; portable scalar tail.
Instruction inspection confirms one RBIT per 16 bytes in the ARM64 loop.
All paths are selected at compile time for the build target.
